Crypto Payments pour Laravel

Ce que fait ce package

Paiements Bitcoin et Ethereum : conversion de taux, adresse unique par paiement, suivi des confirmations, webhooks signés et piste d’audit.

Bitcoin et Ethereum

Testnet et mainnet.

Adresse unique

Une adresse de paiement par transaction.

Confirmations

Suivi des confirmations sur la blockchain.

Conversion

Fiat vers crypto via CoinGecko.

Webhooks

Signature HMAC-SHA256 et nouvelles tentatives automatiques.

API REST

Créer, consulter et lister les paiements, avec tâches planifiées de vérification.

Installation

Le package n'est pas encore publié sur Packagist : on l'installe depuis le dépôt GitHub.

  1. Ajoute le dépôt et installe le package :
    composer config repositories.crypto-payment-laravel vcs https://github.com/martin-lechene/crypto-payment-laravel
composer require martin-lechene/crypto-payments:dev-main
  2. Ensuite :
    php artisan vendor:publish --tag=crypto-payments-config
php artisan vendor:publish --tag=crypto-payments-migrations
php artisan migrate

Exemple

use MartinLechene\CryptoPayments\Services\PaymentManager;

$payment = app(PaymentManager::class)->createPaymentRequest(
    currency: 'BTC',
    amountFiat: 100.00,
    fiatCurrency: 'USD',
    options: ['merchant_id' => 1, 'order_id' => 123],
);
Nécessite un nœud Bitcoin Core (RPC) et un nœud Ethereum compatible JSON-RPC. Lis la section « Known Limitations » du README avant la production.
